📝 HOW IT WORKS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. **Browser Thread**: Runs Playwright/Chromium in dedicated thread
2. **Worker Thread**: Manages campaign flow, gets contacts from Firebase
3. **Message Queue**: Safe cross-thread communication for sending messages
4. **Flask Thread**: Serves web dashboard and API endpoints

ARCHITECTURE:
Worker Thread → Message Queue → Browser Thread → Chromium → WhatsApp Web
